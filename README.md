# Hi, I'm Johan 👋

**Fullstack Product Engineer** based in Paris, France 🇫🇷

I design and build software products end-to-end — from product thinking and application architecture to backend, frontend, automation and infrastructure.

I like working close to the product: understanding the problem, designing the right technical approach, building it, shipping it and keeping it reliable in production.

## What I work on

- **Product engineering** — turning business needs into maintainable software products
- **Full-stack development** — web applications, APIs and internal tools
- **Software architecture** — designing pragmatic and evolutive application architectures
- **Automation** — workflows, integrations and operational tooling
- **Infrastructure & DevOps** — Docker, Linux, cloud infrastructure, CI/CD and observability
- **Open source** — building and maintaining developer-facing tools
